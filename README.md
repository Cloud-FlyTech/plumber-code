# Plumber Code

**Plumber Code** is a Duolingo-style app designed to teach beginners how to code before building their own AI.

## Features (Planned)
- Short interactive lessons in Python, HTML, and AI basics
- Gamified progress tracking (XP, streaks, badges)
- AI-powered hints and explanations
- Lightweight and mobile-friendly interface

## Tech Stack (Planned)
- Frontend: Flutter or React Native
- Backend: Firebase or Supabase
- Content: JSON-based quizzes
